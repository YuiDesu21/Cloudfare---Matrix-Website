# Matrix Landing Page Concept

Files included:

- `index.html` — responsive page structure
- `styles.css` — visual styling and responsive layouts
- `assets/hero-products.png` — local product visual cropped from the supplied website mockup

## Use

Open `index.html` directly in a browser, or open the `matrix-website` folder in VS Code and use Live Server.

The page is static: navigation links scroll to sections; no JavaScript or backend is included.

Before publishing, replace sample phone numbers, email, product details, membership figures, and plan wording with company-approved information and terms.
